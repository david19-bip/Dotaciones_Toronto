Qué falta para pasar a producción
  1. Obtener el certificado digital de firma electrónica (entidad de certificación autorizada) y dejarlo en facturacion.dian.certificado-ruta.
  2. Habilitarse como facturador electrónico en el portal DIAN y descargar el set de pruebas.
  3. Solicitar la resolución de numeración (prefijo, rango y clave técnica) y registrarla en facturacion.numeracion.*.
  4. Registrar el software en el portal DIAN y copiar Software ID y PIN.
  5. Cambiar facturacion.modo=DIAN y facturacion.ambiente=1 cuando la DIAN apruebe la habilitación.
